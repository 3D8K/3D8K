## 🧭 About me

I'm a frontend engineer with 8 years of experience building product-focused web applications, from real-time trading terminals to e-commerce tools used by tens of thousands of merchants. My work sits where frontend architecture, product engineering and AI-driven developer tooling meet. I care about systems that scale across teams, interfaces that stay fast under heavy load, and measurable results that prove the work mattered.

I've worked in fintech, crypto and large-scale e-commerce, in both small startup teams, where I owned whole products end to end, and large organizations, where I set architecture standards across multiple teams. I started coding professionally while still studying Software Engineering at university, and I've been shipping production code ever since.

## 🚀 What I'm doing now

At **Allegro**, the leading e-commerce platform in Central and Eastern Europe with around 20 million active buyers, I lead frontend architecture for the merchant tools domain across four teams and about fifteen engineers. I designed and launched a brand pages product from scratch, taking it from RFC to production in five months with zero critical incidents. I also led the architectural refactoring of a drag-and-drop storefront builder used by more than 25,000 sellers. That refactoring introduced a dedicated domain layer, feature-based code structure, a unified modal system built on state machines, and CI-enforced dependency rules, which halved onboarding time for new engineers.

I also build AI tools that make engineering teams faster. One assistant drafts QA notes from merge request diffs using retrieval-augmented generation over internal docs and past tickets, cutting the work from thirty minutes to under two; six teams now use it. Another is an AI-assisted test generation workflow gated by mutation testing, which raised unit test coverage from 38% to 82%.

## 🛤️ Where I've been

At **CryptoRank**, a real-time crypto market data platform with millions of monthly page views, I spent two years as a senior frontend engineer. I drove the migration from a client-rendered SPA to Next.js with incremental static regeneration for over fifteen thousand pages in six languages, which grew organic search to the majority of total traffic. I re-architected real-time price streaming around a single shared WebSocket with snapshot and delta synchronization, keeping the interface responsive through extreme market volatility. I turned Core Web Vitals work into higher ad revenue, and launched a Web3 portfolio tracker that reached forty thousand connected wallets in its first year.

At **Libertex**, an online broker with a proprietary trading platform, I built core flows of the web trading terminal, including live watchlists, order tickets and interactive chart trading. I delivered regulatory changes for EU retail trading rules through config-driven logic per legal entity, rebuilt KYC document upload for unreliable mobile networks, and helped migrate the client area from AngularJS to React and TypeScript.
